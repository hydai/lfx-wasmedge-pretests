Pre-test

Pre-test 1

Please show the output of the following C++ code snippet:

#include <iostream>
#include <vector>

int filterSum(const std::vector<int>& nums, int limit) {
    int total = 0;
    for (int n : nums) {
        if (n <= limit) {
            total += n * 3;
        } else {
            limit += 1;
        }
    }
    return total;
}

int main() {
    std::cout << filterSum({4, 1, 5, 6, 2, 8, 3}, 5) << '\n';
    return 0;
}

Pre-test 2

To prove you have a basic understanding of executing the WebAssembly binary format and the WasmEdge runtime:

  1. Build WasmEdge from source using the latest master branch.
  2. Create a WASM file that contains SIMD instructions.
  3. Modify the WasmEdge execution engine to print extra information about the SIMD instructions when executing the above WASM file.
  4. Provide the patch files of your modification.
  5. Provide the WASM file you created in WAT format.
  6. Provide the output produced by your modified WasmEdge.

Don't submit your modified code to the WasmEdge repository.

Don't invite the mentors to your private repository. Please submit the patch files and the WASM file in this pre-test report.

Pre-test 3

To prove you have a basic understanding of using the LLVM framework:

  1. Create a simple program that uses the LLVM API to create two i128 integers (a, b), read the inputs, and calculate the result of a + b.
  2. Provide the patch files of your implementation.
  3. Provide the output produced by your program.

Don't submit your modified code to the WasmEdge repository.

Don't invite the mentors to your private repository. Please submit the patch files in this pre-test report.
